# Security policy

## Supported versions

There are no released or supported application versions yet. The default branch is pre-release development and is not suitable for irreplaceable documents until data-integrity validation is complete.

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** feature for this repository:

https://github.com/stultusmundi/theonlypad/security/advisories/new

Do not disclose an unpatched vulnerability in a public issue. Include the affected revision, reproduction steps using synthetic files, expected versus actual behavior, and potential impact. Do not include credentials, private documents, or other personal data.

If private reporting is unavailable, open an issue requesting a private contact channel without including vulnerability details.

There is no guaranteed response-time commitment or bug bounty program.
