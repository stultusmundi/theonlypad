# TheOnlyPad

Text and code editor for macOS.

TheOnlyPad is a planned, offline-first macOS editor inspired by the functional breadth of Notepad++. It aims to combine reliable everyday text editing with advanced search, multi-document workflows, language tools, automation, and extensibility.

**Status: project brief and repository setup. No application or downloadable release exists yet.** Features described here and in the build brief are requirements, not claims of implemented functionality.

## Development

The complete agent build prompt is in [docs/BUILD_PROMPT.md](docs/BUILD_PROMPT.md). Open this repository in your coding agent and ask it to execute that brief. [AGENTS.md](AGENTS.md) defines repository-wide working rules.

Architecture, supported macOS versions, and build commands will be documented when the initial feasibility work establishes them. The intended delivery is a real macOS application, not a web mockup.
