# Architecture and product decisions

- 2026-09-09: Use Swift Package Manager, macOS 14 minimum, AppKit and explicit TextKit 1 NSTextView adapter provisionally. Native engine microbenchmarks justify further work, not final performance acceptance. STTextView's current GPL/commercial terms exclude it from the selected dependency plan; Monaco remains a documented fallback. No third-party runtime package adopted.
- Keep branding/version in `AppIdentity`. Packaging derives metadata from it. Original generated icon uses geometric drawing, not copied assets.
- Split Foundation services from native UI. Synchronous services must run on workers; main actor owns views and commit decisions. Exact UTF16/byte comparison distinguishes canonically equivalent edits.
- Save original paths with expected-byte conflict checks and atomic sibling rename. Save As currently creates a new destination only; replacing a different existing file is refused rather than treating a raced-in file as consented. This limitation remains outstanding. POSIX last-check/rename race with uncooperative external writers and metadata/backup preservation are not solved.
- Restore unsaved original files as untitled recovery buffers. Never silently write recovery content to its historical path. Serial revisions and closed-document tombstones prevent stale snapshots from reappearing. Recovery files are private; checksums detect accidental corruption, not malicious same-user edits.
- Line deduplication compares exact UTF8 bytes, retaining distinct normalization forms and surviving line separators. No implicit encoding or line-ending normalization on ordinary save.
- Regex dialect is ICU, not Notepad++ Boost. Limits and progress cancellation are cooperative, not process isolation. Bounded replacement expansion validates size before capture allocation. Explicitly document supported replacement-template differences.
- Lexical language colors are a bounded small-document service, not semantic intelligence or an incremental parser. Large documents disable highlighting visibly. Full grammar accuracy, completion, folding and outline remain outstanding.
- Accessibility trust is absent. In-process AppKit harnesses establish controller behavior but do not replace actual desktop input, dialog, VoiceOver or IME acceptance. A missing-access question was sent; no security setting changed.
- Work is isolated on local branch `build/native-editor` from an initially clean repository. No other checkout changes existed to preserve; no remote push, merge or publication is authorized or performed.
- SwiftPM required an approved unsandboxed local compiler run because the filesystem sandbox blocked generated build-plan reads. Repository-local module caches reduce machine-specific state; `scripts/swift.sh` captures the reproducible invocation. Hosted CI remains unrun.
