# Bounded in-memory search plan and execution

Scope: partial C-01/C-02/C-03/C-06/C-07/C-08/C-10. This does not complete any feature-family aggregate. Own `Sources/PadCore/SearchService.swift`, `Tests/PadCoreTests/SearchTests.swift` and `docs/verification/search.md`.

Design: Foundation ICU regex supports literal, escaped-text and regex modes through one bounded synchronous service. Use a worker when integrated into UI. Inputs/results use UTF-16 NSRange with scalar-safe scope endpoints. Whole-word matching uses ICU Unicode boundaries against surrounding document text, not artificial selection edges. Regex templates use ICU `$1` capture syntax; literal/escaped-mode replacements are literal strings. Escaped patterns support backslash, newline, carriage return, tab and NUL only; other escapes fail explicitly.

1. Define public query/options/error API and behavioral tests. **Implemented/tested:** initial skeleton made the eight tests fail (13 assertions after precise limit errors were added).
2. Implement modes, scope checks, captures, cancellation and input/result/output limits. **Implemented/tested:** eight tests pass.
3. Exercise pathological regex progress cancellation. **Implemented/tested:** `(a+)+$` with 200 `a` characters and a nonmatching suffix stopped around 20 ms against a 20 ms budget on the local arm64 test host.
4. Investigate scope failure rather than weakening it. **Implemented/tested:** Foundation NSRange conversion allowed a surrogate split; explicit low-surrogate endpoint rejection fixes the regression.
5. Record safety boundaries and actual evidence. **Implemented:** verification record distinguishes cooperative timeout from hard isolation.
