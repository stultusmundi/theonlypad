# Bounded lexical document outline

Own DocumentOutline.swift/tests, OutlineController.swift/native harness and plan. Work isolated and copy only exact green source after notifying root. No registry/editor/script edits.

Support Swift line-leading functions/types/extensions with common declaration modifiers; Python def/class, including async def; JavaScript named function/class with export/default/async; TypeScript additionally interface/type/enum; Markdown ATX headings outside fenced code and HTML comments. Unsupported languages throw unavailable. No semantic resolution, scope tree, anonymous functions, variable/arrow bindings, Swift operator declarations, same-line attributes, Markdown setext headings or font/grammar intelligence claims. This is a captured-snapshot outline.

Reuse DocumentLanguage. Existing LanguageService token spans omit multiline/triple/template/nested-comment constructs needed to hide false symbols; use a dedicated bounded lexical masking pass preserving all UTF16 line offsets. Quotes/comments are blanked without removing CR/LF. Swift raw and triple quoted strings, nested block comments, Python triple strings, JavaScript simple template literals, Markdown fences/comments receive explicit handling. Complex nested template interpolation and embedded languages remain outside this heuristic support.

Hard limits: 2M UTF16 units, 20,000 logical lines, 10,000 symbols, 512 UTF16 units per symbol name. Cancellation before work and regularly during scanning/filtering. Exceeding a limit fails explicitly; no silently truncated symbol list. Returned ranges select symbol name in the original text; lines count CRLF as one, CR and LF as one each. Unicode names use letter/mark/number classes; no normalization of source snapshots.

Native init(text:language:onSelect:(NSRange,String)->Void), optional onClose. Immutable text/language; worker analysis, searchable list labeled kind/line, Return/double-click activation, explicit unavailable/errors, generation and close guards. Root validates snapshot before navigation. TDD: actual comments/strings/declarations, Unicode ranges/mixed endings, Markdown fences, limit/cancel/unsupported; native controls/filter/callback/unavailable/close. No physical GUI automation claim. Initial status planned.
