6. Fresh available core/native checks, local commit/package, and actual desktop invocation/relaunch test when GUI access is restored. Build-for-testing alone is not acceptance. Non-US layouts, physical recorder behavior and standard responder routing remain explicit validation gates.

Frozen core interface: KeyboardShortcut(key:modifiers:) and canonicalString parser; ShortcutProfile(records:) plus decode/encode/defaults, maximumBytes262144/maximumRecords1024; assignment disabled/assigned, omission inherited. Strict JSON version1 contains overrides array of commandID and tagged assignment. Canonical modifier tokens cmd/alt/ctrl/shift match existing default descriptors.

Frozen store intent: read returns raw destination/directory-bound receipt and profile Result; malformed/future bytes preserved for explicit repair. write(profile,matching:receipt) refuses external modification and returns a new receipt only on confirmed success. Missing file uses create-only expectednil. No automatic overwrite of unreadable/oversize/symlink state or chmod of existing unsafe files.

Existing proven regression commands: `scripts/swift.sh test`, `scripts/test-native-integration.sh` (visible portions currently blocked), strict swift-format and public-source checks. New isolated/retained runner commands are recorded only after execution. Neither current isolated component work nor source review establishes H-01 completion.
