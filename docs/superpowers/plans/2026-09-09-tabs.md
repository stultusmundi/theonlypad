# Native document tabs implementation plan

> **For agentic workers:** Execute the assigned subsystem inline with installed TDD and verification skills. BUILD_PROMPT.md authorizes documented routine design review without repeated approval checkpoints.

**Goal:** Provide a native horizontal tab strip and a testable ordering model without owning document close/save policy.

**Architecture:** PadCore supplies unique-ID reorder/close projections and stable pinned-first partitioning. AppKit renders selectable buttons, separate close buttons, contextual actions and UUID-only within-bar native dragging. All actions call the owning editor; the strip does not destroy or save documents.

**Tech stack:** Swift Foundation and AppKit; no dependency or copied asset.

**Spec:** [BUILD_PROMPT.md](../../BUILD_PROMPT.md), A-03/A-04/H-06. Root owns integration in EditorWindowController and AppDelegate; do not edit them.

## Files and interfaces

- `Sources/PadCore/TabOrder.swift`: public `TabItem(id: UUID, title: String, dirty: Bool, pinned: Bool)`; `TabOrder.reordered(items:moving:to:)`, `closingOthers(items:keeping:)`, `closingRight(items:after:)`, `pinnedFirst(items:)`, with duplicate/missing/index errors. Move destination is the final index, within `0..<items.count`; pinned partition is stable.
- `Tests/PadCoreTests/TabOrderTests.swift`: hand-derived reorder/close cases, duplicate IDs, invalid destinations, missing IDs and pinned stability.
- `Sources/TheOnlyPad/DocumentTabBar.swift`: `@MainActor final class DocumentTabBar: NSView`, `init(frame: = .zero)`, `update(items: [TabItem], selectedID: UUID?)`; optional callbacks `onSelect`, `onClose`, `onPin`, `onCloseOthers`, `onCloseRight` (UUID), `onMove` (UUID, Int).
- This plan records tests and native harness evidence. No other tracked files or commits are owned by this task.

## Reviewed decisions

- Use real NSButtons for selection/close and NSMenu context commands, with accessible names including selection, dirty and pinned state. A horizontal NSScrollView handles overflow. No fabricated result/control is exposed.
- Clicking a title selects; dragging past a small native threshold begins an NSDraggingSession. Pasteboard contains only the tab UUID under an identity-derived local type. Destination accepts only this same strip as source and a known UUID, so unrelated/external drag payloads cannot target document operations.
- Destination indices stay within the source tab's pinned group. Context Move Left/Right provides keyboard-accessible reorder and does not offer crossing a pinned boundary. Root still applies stable pinned-first ordering and performs dirty-document confirmation for every close callback.
- Alternatives: an NSPopUpButton cannot provide actual horizontal tabs/drag affordance; NSTabView owns content/policy unsuitable for this reusable strip; custom raw drawing would require rebuilding native accessibility. Chosen native button composition preserves separation.
- Unique IDs are an internal contract; model functions reject duplicates. `update` expects valid editor identities and does not infer document save/close rules.

```sh
mkdir -p .build/tabs-harness
swiftc -module-cache-path .cache/swift -parse-as-library -I .build/tabs/arm64-apple-macosx/debug/Modules Sources/TheOnlyPad/DocumentTabBar.swift .local/tabs-harness.swift .build/tabs/arm64-apple-macosx/debug/PadCore.build/*.o -o .build/tabs-harness/tabs-harness
.build/tabs-harness/tabs-harness
```

The module path records the tested arm64 environment; it is not a claim of Intel testing.

```swift
import AppKit
import PadCore

@main struct TabsHarness {
  enum Failure: Error { case failed(String) }
  @MainActor static func main() throws {
    _ = NSApplication.shared
    let a = UUID(), b = UUID(), c = UUID()
    let bar = DocumentTabBar(frame: NSRect(x: 0, y: 0, width: 300, height: 44))
    let window = NSWindow(contentRect: bar.frame, styleMask: [.titled], backing: .buffered, defer: false)
    window.contentView = bar
    var selected: UUID?, closed: UUID?, pinned: UUID?, others: UUID?, right: UUID?
    var moved: (UUID, Int)?
    bar.onSelect = { selected = $0 }; bar.onClose = { closed = $0 }; bar.onPin = { pinned = $0 }
    bar.onCloseOthers = { others = $0 }; bar.onCloseRight = { right = $0 }; bar.onMove = { moved = ($0, $1) }
    bar.update(items: [TabItem(id: a, title: "Pinned", dirty: false, pinned: true),
                       TabItem(id: b, title: "Working", dirty: true, pinned: false),
                       TabItem(id: c, title: "Third", dirty: false, pinned: false)], selectedID: b)
    bar.layoutSubtreeIfNeeded()
    func require(_ value: @autoclosure () -> Bool, _ description: String) throws {
      guard value() else { throw Failure.failed(description) }
    }
    func find(_ id: String) throws -> NSButton {
      func descend(_ view: NSView) -> NSButton? {
        if view.identifier?.rawValue == id { return view as? NSButton }
        for child in view.subviews { if let found = descend(child) { return found } }
        return nil
      }
      guard let result = descend(bar) else { throw Failure.failed("Missing tab button: \(id)") }
      return result
    }
    let active = try find("tab.select." + b.uuidString)
    try require(active.title.contains("●") && active.state == .on, "Dirty selected state must be visible")
    try require(active.accessibilityLabel()?.contains("unsaved") == true, "Accessible dirty state missing")
    let pinnedButton = try find("tab.select." + a.uuidString)
    try require(pinnedButton.accessibilityLabel()?.contains("pinned") == true, "Accessible pinned state missing")
    active.performClick(nil)
    try require(selected == b, "Selection callback wrong")
    try require(active.state == .on, "Clicking selected tab must retain selected appearance until owner updates")
    try find("tab.close." + b.uuidString).performClick(nil)
    try require(closed == b, "Close callback wrong")
    guard let menu = active.menu else { throw Failure.failed("Missing context menu") }
    for title in ["Pin Tab", "Close Other Tabs", "Close Tabs to the Right", "Move Right"] {
      guard let item = menu.item(withTitle: title), let action = item.action else { throw Failure.failed("Missing context action") }
      try require(item.isEnabled, "Expected context action enabled")
      _ = NSApp.sendAction(action, to: item.target, from: item)
    }
    try require(pinned == b && others == b && right == b, "Context callbacks wrong")
    try require(moved?.0 == b && moved?.1 == 2, "Move callback must use final index")
    try require(menu.item(withTitle: "Move Left")?.isEnabled == false, "Cannot move into pinned group")
    guard let scroll = bar.subviews.first as? NSScrollView else { throw Failure.failed("Missing horizontal scroll view") }
    try require((scroll.documentView?.frame.width ?? 0) > scroll.contentView.bounds.width, "Tabs must overflow into horizontal scroll")
    window.close()
    print("PASS: native tab controls, callback routing, state labels, context actions and scrollable overflow")
  }
}
```
