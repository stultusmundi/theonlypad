# TheOnlyPad implementation plan

> Use Superpowers subagent-driven development and independent review. Routine approval gates are waived by BUILD_PROMPT.

**Goal:** Implement and verify the complete desktop editor scope in BUILD_PROMPT.

**Architecture:** Foundation core services with native editor adapter and AppKit application. Provisional macOS 14 minimum; editor choice gated by feasibility.

**Spec:** ../specs/2026-09-09-architecture-design.md

## Global constraints

Offline core; original MIT code; no private data in tracked files; no remote publication; preserve unverified and outstanding statuses. Use synthetic fixtures. No telemetry or automatic project command execution.

## Execution sequence

- [ ] 1. Compare editor engines, run native selection/Unicode/undo/large-file probes, record accessibility automation access. Own `.local/spikes` and `docs/verification/editor-feasibility.md`.
- [ ] 2. Produce exhaustive requirement/parity matrix with stable IDs and acceptance evidence. Own `docs/requirements-matrix.md` and `docs/reference-parity.md`.
- [ ] 3. Foundation document integrity: `Sources/PadCore/DocumentCodec.swift`, `AtomicFileStore.swift`, `RecoveryStore.swift`; corresponding XCTest files. Interface: `DocumentCodec.decode(Data) throws -> DecodedDocument`, `DocumentCodec.encode(DecodedDocument) throws -> Data`; immutable text/encoding/BOM metadata. Tests first: byte round trips, invalid data, injected write failure, external modifications, corrupt recovery. Proposed command `swift test --filter Document`; record as proven only after execution.
- [ ] 4. Native runnable application, central identity, command registry, documents/tabs/windows, open/save/close and recovery integration. Verify real desktop behavior, not just build.
- [ ] 5. Advanced editing and encoding UI; search service and cancellable folder search with replacement previews and backups. Unit/property tests and actual UI workflows.
- [ ] 6. Language support, splits/workspaces, themes, developer tools. Explicit capability inventory and representative language fixtures.
- [ ] 7. Macros, explicit external commands, versioned extension API and sample, preferences, CLI and macOS integration.
- [ ] 8. Accessibility, fault injection, force termination recovery, 1 MB through 1 GB performance, security and dependency review.
- [ ] 9. Local app/archive packaging, clean launch workflow, CI, SBOM, documentation, independent final review and scoped local commits.
