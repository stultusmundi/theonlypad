# Monitor endpoint reattachment

A document retains its existing DocumentFileStateController across endpoint loss. Before terminal invalidation, its owner calls `detachEndpoint()` and retains the opaque owner/issuance token. The token's binding identity includes document ID, file binding ID, baseline revision, URL and optional model ownership generation. Managed callers supply the real model generation in FileStateLiveContext; nil remains legacy compatibility.

Detachment retires action/delivery authority and clears endpoint callbacks before callback-capable cancellation. The registration's atomic cancel-and-snapshot receipt preserves bound parent continuity only for its installed binding. The bridge retains immutable baseline bytes and parent identity, but cannot accept observations, perform checks or authorize actions while detached. A delayed closed-endpoint reconciliation does not terminally invalidate detached state.

`reattachEndpoint(_:expectedBinding:liveContext:onChange:)` requires the exact unconsumed token and original binding/model identity. It validates the new context, then rechecks after that callback. Detachment also establishes its transition guard before reading the outgoing context, rejecting recursive calls. Reattachment checks the original binding and newly issued registration authority again after rendering; a reentrant baseline replacement cannot produce an obsolete success. Failed preflight preserves detached retry capability. Successful acceptance installs fresh endpoint callbacks and registers against the retained parent identity. Registration failure explicitly enters manual fallback with that same continuity; it does not erase the binding. A consumed token cannot attach twice. Terminal invalidate cannot be undone.

No text, undo manager, model generation, encoding, baseline or history data is changed. No baseline bytes are reread, scanned or decoded during reattachment. Existing URL equality behavior is preserved; reattachment does not canonicalize a path or grant symlink/parent replacement permission. Changed model/baseline identity requires separate reviewed ownership reconciliation and cannot be accepted by changing the expected token fields.

Native controller integration must detach before its existing terminal invalidate path, retain the token with process ownership, and provide callbacks belonging to the replacement endpoint. This bridge slice does not implement those controller callsites or claim complete native monitoring transfer.
