# Native controller routing

Application mode installs required process callbacks before any document creation. It projects exact active registry handles into one native window/group; the legacy initializer remains available until complete process composition is verified. No default close/reopen callback silently succeeds.

Scratch, opened file, backup, duplicate, prepared restoration and checked disk copy submit immutable prepared seeds. File I/O, decoding, language detection and position preparation occur off-main. The process intake owns admission/adoption; successful UI completion and MRU updates wait for exact projection. Disk-copy source authority is consumed synchronously before returning to the action coordinator; subsequent ownership belongs to the submitted seed and destination context.

A no-op projection preserves storage, undo, selection, pane identities and process-owned character observers. Stale endpoint/revision, wrong assignment or inactive adoption refuses projection. Managed capture uses captured model authorities through the single paired publisher; legacy standalone recovery calls refuse managed documents.

This slice does not activate AppDelegate or complete native close, endpoint recreation, monitor reattachment, group transfer or quit admission. Those require explicit adapters and failure tests. Window identity validation must remain separate from user admission so process projection and final capture work under closed user admission.
