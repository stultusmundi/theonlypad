# Notepad++ reference parity

Research baseline: 2026-09-09. Consulted the [official manual repository](https://github.com/notepad-plus-plus/npp-usermanual) and its current `master` documentation through the web tool. The rendered documentation site returned HTTP 403, so the official repository was used. These are moving links, not a claimed immutable upstream release snapshot. No Notepad++ source, documentation passages, branding or assets are incorporated. The brief remains authoritative where it calls for stronger data protection or platform adaptation.

**Classification:** implemented equivalent requires functional evidence; macOS adaptation describes the chosen platform design but does not imply implementation; Windows-specific/not applicable requires a concrete platform reason; outstanding means an applicable unmet or unverified obligation. At this baseline, every applicable feature is outstanding. Planned macOS adaptations are recorded separately from actual classification to avoid implying completion. Syntax highlighting is not semantic intelligence, and a plugin framework is not binary compatibility or the entire third-party ecosystem.

Windows Control-key defaults, full-screen conventions, installation paths and settings storage are **macOS adaptations**, not excluded editor functionality. The eventual regex engine must document concrete dialect differences under C-10; this baseline makes no compatibility claim. Updater integration is conditional under PUB-12, and remote distribution remains separately authorized. Additional reference research can append IDs without renumbering or shrinking any existing scope.
