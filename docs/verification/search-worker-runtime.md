It writes one complete response and terminal before acknowledging and reading the next request. Request-heavy ownership is released inside an autorelease pool before terminal emission. Only a SearchError thrown by the direct engine call becomes a semantic failure; callback/input/output/local errors remain fatal with their actual origin.
