## Implemented privately

The native manager displays stable profile IDs and edits local raw forms. It
creates, edits and stages deletion before an explicit genuine catalog Save.
Standalone import stages a definition without saving the catalog; exclusive
export preserves an existing destination. Pending-publication Verify reads real
evidence without acknowledging Save. Retry clears the draft only after the
owner returns an actual matching publication. Inspection displays unsupported
format status without automatic repair or changing catalog bytes.

Pure local New/form editing remains available after an unsupported catalog read,
while durable actions retain confirmed-store admission. Newer native input during
a pending Save prevents Retry from erasing that input. Explicit controller and
direct native window close retire the exact manager before close callbacks;
callback-created successors remain cached. Real completed application tasks
retire after their completion callbacks return, preserving callback-created work.
Authentic retained pending drafts survive close/reopen, and a genuine successful
Retry restores Save availability for the next local edit.

Advanced controls now stage indentation, paired block delimiters, decimal-number
highlighting and up to four literal quote rules. They validate through the Core
definition and catalog rules. Apply stages only the selected local form; Save
still requires the actual owner/store publication. Raw Unicode, unselected
profiles and built-in overrides are preserved. Cancel and stale Apply do not
erase newer parent input. Visible error presentation remains outstanding.
